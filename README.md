# genzagents plugin marketplace

Claude Code plugins from [genzagents](https://github.com/genzagents).

```bash
claude plugin marketplace add genzagents/marketplace
claude plugin install citable@genzagents
```

| Plugin | What it does |
|---|---|
| [citable](https://github.com/genzagents/citable) | Can ChatGPT, Claude and Perplexity read and cite a site? MCP server (`check_site`, `draft_llms_txt`) plus a skill that turns the report into edits. |
